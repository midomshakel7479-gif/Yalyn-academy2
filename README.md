# أكاديمية يالين - نسخة Render الجاهزة للرفع 🚀

تم إعداد وتجهيز هذا المشروع بالكامل ليعمل بسلاسة ومجاناً على منصة **Render** بدلاً من **Vercel**، لحل مشاكل الـ Timeout وقيود حجم ملفات الـ PDF بشكل نهائي.

---

## 📁 محتويات المجلد:
1. `server.js`: خادم Express دائم ومجهز لاستقبال أحجام ملفات كبيرة (حتى 50MB) بدون انقطاع.
2. `package.json`: يحتوي على أوامر التشغيل والمكتبات اللازمة.
3. `api/extract-pdf.js`: استخراج نصوص الـ PDF بدقة وكفاءة.
4. `api/generate-questions.js`: توليد الأسئلة عبر أحدث نماذج الذكاء الاصطناعي (Gemini 1.5 Flash).
5. `api/grade-answers.js`: تصحيح الإجابات ورصد النسب المئوية وتقديم شروحات توضيحية.
6. `public/index.html`: واجهة مستخدم عربية احترافية، تدعم رفع الـ PDF، لصق النصوص، والاختبار التفاعلي المباشر.

---

## 🛠️ خطوات الرفع والتشغيل على Render (خلال 3 دقائق):

### الخطوة 1: رفع المشروع على GitHub
1. فك الضغط عن هذا المجلد (`yalyn-academy-render`).
2. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub وقم برفع ملفات المجلد داخله.

### الخطوة 2: الربط بـ Render
1. سجّل الدخول إلى [Render.com](https://render.com).
2. اضغط على الزر الأزرق **New +** ثم اختر **Web Service**.
3. اختر **Build and deploy from a Git repository** ثم اربط مستودع GitHub الذي أنشأته.

### الخطوة 3: ضبط الإعدادات
* **Name:** `yalyn-academy` (أو أي اسم تفضله)
* **Language:** `Node`
* **Branch:** `main`
* **Build Command:** `npm install`
* **Start Command:** `npm start`
* **Instance Type:** اختر **Free**

### الخطوة 4: إضافة مفتاح الذكاء الاصطناعي (مهم جداً 🔑)
1. في نفس الصفحة انزل لأسفل إلى قسم **Environment Variables**.
2. أضف المتغير التالي:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** (مفتاح API الخاص بك من Google AI Studio مجاناً)
3. اضغط على **Create Web Service**.

🎉 مبروك! سيعطيك Render رابطاً مجانياً ودائماً للموقع يعمل بكفاءة وبدون أي مشاكل في توليد الأسئلة.
